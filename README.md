# JUAN XAUUSD — landing

Sitio estático, sin dependencias. Para abrirlo, sirve esta carpeta con cualquier servidor local (por ejemplo `python3 -m http.server 8000`) y visita `http://localhost:8000`.

Antes de publicar, edita `WHATSAPP_NUMBER` al inicio de `script.js` con el número en formato internacional, solo dígitos. El botón queda sin destino mientras el número esté vacío para evitar enlazar a un contacto incorrecto.
